# 광영님 최종 인터뷰 요약 (2026-03-27)

> [!info] Whisper 트랜스크립트 기반 요약
> 음성 품질/한국어 인식 한계로 일부 내용이 부정확할 수 있음

## 1. B2B 세일즈 자동화 논의

### 현재 세일즈 프로세스
- 인바운드 → 데모/POC → 제안서 → 최종 미팅 → 계약
- 수작업 비율 높음 (연 30회+, 건당 2~3시간)

### 광영님 제안
- **페르소나 분석 에이전트**: 고객 채널/레퍼런스 분석 → 맞춤 제안서 자동 생성
- **데모/POC 자동화**: 고객이 직접 URL 입력 → 샘플 콘텐츠 제작 → 제안서까지 셀프서비스
- **팔로우업 자동화**: 리마인드 템플릿 → 이메일/문자 자동 발송
- **미팅 일정 자동화**: 캘린더 연동

### 핵심 논점
- **퍼스널 터치 vs 자동화**: 최종 결정 미팅은 퍼스널 터치 필수, 나머지는 자동화 가능
- **타겟층 중요**: 특화된 산업군에 퀄리티 보장 → 해당 영역에서 성장 후 확장
- **가격 공개**: B2B 고객에게 가격 정보 공개가 신뢰도 높임 (고정 가격 + 고객 규모별 조정)

## 2. 제안서 자동화 워크플로우 설계 (과제)

광영님이 제시한 워크플로우:
1. 고객 정보 입수 (URL, 레퍼런스 채널, 페인포인트)
2. AI가 베이스 템플릿 기반 제안서 커스터마이즈
3. **HTML 형태로 관리** (LLM이 다루기 가장 편한 아웃풋 형태)
4. 수정/미수정 부분 스타일 분리
5. 고객 컨펌 페이지 제공 (수정 하이라이트)
6. PDF 등으로 최종 출력

### 커스터마이즈 핵심
- 산업별 특화 편집점 예시 (ex. 아이돌 칼군무 하이라이트)
- 고객 페인포인트에 맞춘 솔루션 표현

## 3. AI 활용 역량

### 코딩
- Codex 사용 중이나 현 회사에서는 보수적으로 활용 (컨펌 문화)
- 범위를 좁혀서 사용 (반복 작업, 해싱, 보일러플레이트)
- **가독성 문제 인식**: AI가 작성한 코드의 가독성이 떨어지는 한계 인지
- 인터페이스/모듈을 직접 정의 후 AI에게 구현 위임

### 코딩 외
- **키워드 추출**: 직관적 느낌 → AI로 키워드 추출 → 조사 → 제안서 작성
- **디자인**: 앱 디자인 시 AI 활용
- **시장 조사**: 리서치에 활용

### 에이전트 경험
- 직접 만들어본 경험 없음 (러닝커브 필요 인정)
- LLM 활용한 실험적 접근에 대한 감각/노하우 부족 인지

## 4. 경력/성장 배경

### 삼성 (LSI)
- 산화막 관련 업무
- 체력/체세수기 성장

### 현 직장 (TR - 의료기기)
- 안드로이드 → 백엔드(스프링) 전환
- 하드웨어 제품 세일즈 경험 (SBS 아카데미 영업 사례)
- **폐기능 측정기** 관련 연구/개발
- 프로젝트 설계 실패 경험: 안드로이드 앱 → 클라우드 → 다시 안드로이드 (아키텍처 파악 실패)
- 공통 라이브러리 서버(Nexus) 구축으로 해결

### 이직 사유
- 하드웨어팀과 소통 이슈, 개발 파트에 결정 권한 부재
- 개발 외 업무(설치, 병원 정산, 영업) 과다
- 퀄리티 이슈 인식하나 해결 권한 제한

## 5. 피카디 합류 관련

### 지원 동기
- JS/NestJS 학습 욕구 (이전에 그로스 해커 지향 → 개발+마케팅 겸비)
- 대표님 시간을 덜어드리는 것이 목표
- "대표님이 편하게 의사결정 내릴 수 있으면 성공"

### 입사 후 우선순위
1. 대표의 시간을 뺏는 부분 파악 → 자동화
2. 로스(loss) 포인트 파악 → 효율화

### 강점 자가진단
- 다양한 이해관계자 목소리 정리 → 팀 전파 → 성과 반영
- 고객 불만 직접 듣고 → 배치로 모아서 해결하는 패턴
- 거짓말 못하는 성향 (솔직한 세일즈)

### 기술 스택 논의
- Java 도입 가능성 70~80% 긍정
- AI가 가장 잘 쓰는 언어 = Java (코드량/라이브러리 풍부)
- 자동화 도구는 JS/Python이 더 적합 (버리는 코드 철학)
- **AI가 잘 작성하게 만드는 환경 세팅이 더 중요** (모두 동의)

## 6. 과제 지연 관련
- 퇴근 후 작업 계획이었으나 야근 과다로 지연
- 사연 기간에 완료
- 먼저 연락/공유하지 않은 점은 아쉬움
